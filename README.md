\# Sales Interaction Intelligence



An LLM-powered NLP system for analyzing salesperson-customer interactions.



\## Objective



The system analyzes salesperson interaction notes and identifies:



\- Sentiment

\- Customer follow-up requirement

\- Customer interest

\- Interested product

\- Not-interested product

\- Customer intent

\- Recommended action



\## Architecture



Salesperson

→ Web Application

→ Backend API

→ NLP / LLM Engine

→ Structured Analysis

→ Recommendation

→ Dashboard



\## Tech Stack



\- Frontend: React / Next.js

\- Backend: Python / FastAPI

\- NLP: LLM API

\- Database: PostgreSQL
